## 2. ตั้งค่า Google Sheet (ทำครั้งเดียว)

1. เปิด Google Sheet  
   https://docs.google.com/spreadsheets/d/1iyxRCc532s3NlFGmMoEkWqnautD9RrXQz4nvPUEY9pc/edit
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ `apps-script/Code.gs`
4. (แนะนำ) เปลี่ยนบรรทัด `const TOKEN = 'pakchom2569';` เป็นรหัสของหน่วยงานเอง
5. กด **บันทึก** (ไอคอนแผ่นดิสก์)
6. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่**
   - ไอคอนฟันเฟือง → เลือก **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
7. กด **ทำให้ใช้งานได้** → **ให้สิทธิ์เข้าถึง** → เลือกบัญชี Google  
   (ถ้าขึ้น "Google ไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง → ไปที่ … (ไม่ปลอดภัย)** → **อนุญาต**)
8. คัดลอก **URL เว็บแอป** ที่ลงท้ายด้วย `/exec`

> ระบบจะสร้างหัวตารางให้อัตโนมัติเมื่อมีการบันทึกครั้งแรก:  
> Timestamp · เลขคิว · เลขประจำตัวประชาชน · ชื่อ-นามสกุล · เพศ · วัน/เดือน/ปี เกิด · สัญชาติ · หมู่เลือด · ข้อมูลที่อยู่(ปัจจุบัน) · จังหวัด · อำเภอ · ตำบล · หมายเลขโทรศัพท์

**ทดสอบ:** เปิด URL นี้ในเบราว์เซอร์  
`<URL เว็บแอป>?action=list&token=pakchom2569`  
ต้องเห็นข้อความ `{"ok":true,"rows":[]}`

> ⚠ ถ้าแก้โค้ด Apps Script ภายหลัง ต้องกด **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชัน: ใหม่** ทุกครั้ง

## 3. ใส่ URL ให้แอปเชื่อมต่ออัตโนมัติ

เปิดไฟล์ `index.dc.html` ด้วยโปรแกรมแก้ข้อความ (Notepad / VS Code) ค้นหาบรรทัด

```js
const DEFAULT_SCRIPT_URL = '';
const DEFAULT_TOKEN = 'pakchom2569';
```

แก้เป็น

```js
const DEFAULT_SCRIPT_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
const DEFAULT_TOKEN = 'pakchom2569';   // ต้องตรงกับ TOKEN ใน Code.gs
```

บันทึกไฟล์ — ทุกเครื่องที่เปิดแอปจะเชื่อมต่อ Google Sheet เองทันที

*(ทางเลือก: ไม่แก้ไฟล์ก็ได้ ให้เปิดแอป → แท็บ **ตั้งค่า** → วาง URL + Token แต่ต้องทำทีละเครื่อง)*

## 4. นำขึ้น GitHub Pages

1. สมัคร/เข้าสู่ระบบ https://github.com
2. กด **New repository** → ตั้งชื่อ เช่น `pakchom-health` → เลือก **Public** → **Create repository**
3. กด **uploading an existing file** → ลากไฟล์ทั้งหมด (`index.html`, `index.dc.html`, `support.js`, โฟลเดอร์ `apps-script`, `README.md`) → **Commit changes**
4. ไปที่ **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **(root)** → **Save**
5. รอ 1–2 นาที จะได้ลิงก์  
   `https://<ชื่อผู้ใช้>.github.io/pakchom-health/`

เปิดลิงก์บนมือถือ → เมนูเบราว์เซอร์ → **เพิ่มไปยังหน้าจอหลัก** เพื่อใช้งานเหมือนแอป

## 5. การใช้งาน

- **ภาพรวม** — จำนวนผู้ลงทะเบียน, สัดส่วน พระภิกษุ/สามเณร/แม่ชี, รายวัน, ช่วงอายุ, หมู่เลือด, เพศ, ตำบล (แตะประเภทเพื่อกรอง)
- **ลงทะเบียน** (ปุ่มมุมขวาบน หรือแท็บล่าง) — กรอกครบแล้วกด **บันทึกการลงทะเบียน** → ระบบกลับหน้าแดชบอร์ดพร้อมแสดงเลขคิว
- **รายชื่อ** — ค้นหาชื่อ/เลขบัตร/เลขคิว/ตำบล, แตะเพื่อดูรายละเอียด, **ส่งออก CSV**
- **ตั้งค่า** — สถานะการเชื่อมต่อ, ดึงข้อมูล, ส่งข้อมูลค้าง, เปิด/ปิดข้อมูลตัวอย่าง

**การซิงก์อัตโนมัติ:** บันทึกในเครื่องก่อนเสมอ แล้วส่งเข้า Sheet ทันที · ส่งข้อมูลค้างและดึงข้อมูลล่าสุดทุก 30 วินาที / เมื่ออินเทอร์เน็ตกลับมา / เมื่อเปิดแอป

**การตรวจสอบข้อมูล:** เลขบัตรประชาชน 13 หลัก (ตรวจ checksum) · กันลงทะเบียนซ้ำ · ชื่อต้องมีนามสกุล · วันเกิดต้องไม่เป็นอนาคต · เบอร์โทรขึ้นต้น 0 และมี 9–10 หลัก · ที่อยู่รองรับเฉพาะจังหวัดเลย

## 7. แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| หน้าเว็บว่าง | ตรวจว่า `support.js` อยู่โฟลเดอร์เดียวกับ `index.dc.html` |
| "เชื่อมต่อไม่สำเร็จ" | ตรวจ URL ลงท้าย `/exec`, Token ตรงกัน, สิทธิ์เว็บแอปเป็น **ทุกคน** |
| ข้อมูลไม่ขึ้น Sheet | แท็บตั้งค่า → **ส่งข้อมูลค้าง**; ถ้าแก้ Code.gs ต้อง deploy เวอร์ชันใหม่ |
| "เลขนี้ลงทะเบียนแล้ว" | มีเลขบัตรนี้ใน Sheet อยู่แล้ว (ระบบกันซ้ำ) |
| เลข 0 หน้าเบอร์หาย | โค้ดใส่ `'` นำหน้าให้แล้ว หากยังหาย ตั้งคอลัมน์เป็นรูปแบบ **ข้อความธรรมดา** |

> **ความเป็นส่วนตัว:** ข้อมูลเลขบัตรประชาชนเป็นข้อมูลส่วนบุคคล (PDPA) — ใช้ Token ที่คาดเดายาก และไม่เผยแพร่ URL เว็บแอป
